# makefun-excuse-skipping-meeting

Entry for the make.fun bounty "The Funniest Excuse for Skipping a Meeting". `main.py` writes one line, at most 200 characters, to `/output/entry.txt`:

> Sorry, I can't make the meeting — my calendar invited me to a meeting about the meeting, and I'm still recovering from the last one.

## Run it

```sh
python3 main.py
```
